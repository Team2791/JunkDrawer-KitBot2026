# Meet Junk Drawer

This is the robot code for our Junk Drawer robot with 2026 kitbot mechanism on top
The only thing that is different in this branch is that this branch has YAGSL implementation for the drivetrain, and there is barely any subsystems implemented here yet...

## Setup

1. If using the radios
    1. Take out the radio labeled "Laptop Access Point" or "Laptop AP". Plug it into the
       wall using the PoE wall adapter, using the "RIO" port on the radio.
    2. Connect the radio to the laptop using the "DS" port
    3. Turn on the robot and a blue light should appear on the Laptop AP.
3. Pull the code
    ```bash
    git clone https://github.com/Team2791/JunkDrawer-KitBot2026
    ```
4. Open the code in VS Code
5. Deploy the code to the robot
